## 🧠 Fun Facts from the World of Data Science

- **Florence Nightingale used data visualizations to save lives — in the 1800s!**  
  The famous nurse used data charts (like the “coxcomb” diagram) to show how unsanitary conditions caused more soldier deaths than wounds. Her work helped revolutionize health policy — with data!

- **80% of a data scientist’s time is spent cleaning data. We're basically fancy janitors.**  
  The actual modeling and “AI magic” takes maybe 20%. The rest is just tidying up messy spreadsheets and weird formats. So yes, we’re basically data janitors with PhDs. 🧽😄

- **The Titanic dataset is the "Hello World" of machine learning.**  
  The Titanic passenger dataset is so famous and used so often in tutorials that some people joke: *“If you can’t save passengers, you can’t be a data scientist.”* 🚢

- **There's a dataset of sneezes. Yes, sneezes. Achoo! 🤧**  
  From toilet flushing sounds to cat meows to human sneezes — if you can think of it, someone probably turned it into a dataset. Check [Kaggle](https://www.kaggle.com/) or [OpenML](https://www.openml.org/) — you’ll be amazed!

- **Data is the new oil… but don’t forget it needs refining first!**  
  This quote is popular in the data world, but people forget that crude oil isn’t useful until it’s refined — just like raw data.  
  📌 A good reminder: **Collecting is not enough. Clean, analyze, act!**
